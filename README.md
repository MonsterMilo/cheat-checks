# Cheat Checks

Beta. Advanced anticheat with 16 checks for bridging, movement and combat. Works in game and replays

## Requires

- hypixel-mod-api

## Commands

- `/check <player>`: Show a player's check levels
- `/flags`: Who flagged this game
- `/mute <player>`: Hide or show a player's flags
- `/status`: Show what the checks see
